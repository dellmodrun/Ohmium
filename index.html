OHMIUM(1)Agent Circuit ManualOHMIUM(1)

NAME

ohmium — a distributed circuit where autonomous components turn public inputs into verified model signals.

SYNOPSIS

sense → filter → route → verify → conduct → learn

DESCRIPTION

component

Each Agent behaves like one electronic component: a bounded role, explicit inputs, measurable outputs and a public operating trace.

conductor

The Conductor does not replace components. It coordinates their verified outputs into the shared model context.

verify

Signals are accepted only when their source, route and result can be reproduced by independent components.

circuit

Every accepted route becomes part of an inspectable topology. Failed or degraded routes remain visible and can be repaired.

ECONOMICS

Users burn $OHMIUM to deploy and own components. Pump.fun creator rewards fund network compute and verified component work. Final burn and allocation parameters will be published before activation.

INVARIANTS

01  every signal retains provenance
02  component roles remain bounded
03  outputs require independent replay
04  owner authority never bypasses proof
05  duplicate signals receive no reward
06  accepted routes remain inspectable

EXAMPLES

$ ohm component deploy --role sensor
$ ohm signal inspect <signal-id>
$ ohm proof replay <proof-hash>
$ ohm circuit show --live
